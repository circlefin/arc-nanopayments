# Security Policy

## Reporting a Vulnerability

Please do not file public issues on GitHub for security vulnerabilities.

Report privately through Circle's [Bug Bounty Program](https://hackerone.com/circle-bbp). Read the program policy and **confirm this repository is listed as an in-scope asset** before submitting.

If `arc-nanopayments` (or another Arc sample app) is not listed in the current circle-bbp scope, do not assume HackerOne intake applies — use the contact channel documented on the program page for out-of-scope / ambiguous assets, or wait for maintainers to clarify the intended reporting path for this repo.

See also: circlefin/arc-escrow has the same SECURITY.md → circle-bbp routing pattern; scope listing should stay consistent across public Arc sample apps.
